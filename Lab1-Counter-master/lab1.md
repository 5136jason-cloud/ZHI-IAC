# Lab 1: Learning SystemVerilog with Verilator and Vbuddy

## Overview

This repository contains my work and logbook for Lab 1 of the
Instruction Architectures and Compilers module.

This laboratory introduces SystemVerilog hardware design, C++ testbenches,
Verilator simulation, GTKWave waveform analysis and interaction with the
Vbuddy development board.

<span style="color: red; font-weight: bold;">
Challenge implementations are stored in separate folders so that the original task code remains unchanged.</span>
