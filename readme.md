# Instruction Architectures and Compilers — Laboratory Logbook

## Overview

This repository contains my laboratory work and technical logbook for the **Instruction Architectures and Compilers (IAC)** module.

The laboratories introduce digital hardware design using SystemVerilog, hardware simulation with Verilator, waveform analysis with GTKWave, interaction with the Vbuddy development board, memory-based signal generation and, later, processor architecture and compilation concepts.
